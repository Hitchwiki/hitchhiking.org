We are hitchhiking geeks building moneyless, free and open-source projects that help people share knowledge and meet in real life.

Chat

Hitchat connects the Hitchhiking community across Matrix and Signal. Hitchwiki and Trustroots members can read recent messages directly on this site.

The room is #hitchat:hitchhiking.org. It is managed by the hitchhiking.org team and bridged two ways with the community Signal group using the mautrix-signal project.

Meta

#meta:hitchhiking.org is a place to discuss technical and other community issues that are not directly about hitching and low-budget travel.

Federation, not a separate chat

Someone with @alex:matrix.org, or an account on any other compatible homeserver, can join the same room. Participating Matrix servers synchronise that room; no Hitchhiking account or Nostr identity is required for direct Matrix access.

The room does not need a duplicate on matrix.org just to include matrix.org users.

What the Nostr check does

The web chat page automatically uses a browser NIP-07 signer and verifies that its key currently matches an @hitchwiki.org or @trustroots.org NIP-05 identity. After a private one-time authorization, the page shows recent room messages.

The check controls the on-site timeline only. It does not make the Matrix room private and does not create a Matrix account.

How messages reach the page

The browser never receives Matrix credentials. After NIP-05 verification, a same-origin backend uses a non-admin Matrix reader account to return bounded recent timelines from Hitchat, Meta and Test containing plain text, notices and emotes.

#test:hitchhiking.org also accepts web messages through @webchat:hitchhiking.org. That account is joined only to Test and Meta, never Hitchat. Each web message starts with an italic by link to the verified Trustroots profile, or the Hitchwiki user page once Hitchwiki NIP-05 is ready. Test messages expire locally after 24 hours.

Membership changes, encrypted events, media, edits and redactions are not rendered on the page. To participate in Hitchat or Meta, or see complete room features, use a Matrix client or the Signal group.

Privacy and responsibility

Participating homeservers keep a copy of events for their users in a room. The hitchhiking.org team can apply its own policies to accounts and rooms it administers, but cannot control other homeservers or their users. Nostr private keys stay with the signer and Matrix credentials stay on the server.
